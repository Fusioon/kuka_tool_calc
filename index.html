    How the maths works
    
    
      
  • KUKA orientation is A about Z, then B about the new Y, then C about the new X: R = Rz(A)·Ry(B)·Rx(C).
    • 
      
  • A taught point P is the TCP pose in the base. The robot puts its flange at F = P · Tool⁻¹.
    • 
      
  • To move every point by D (in the tool frame), the new tool is Toolnew = Tool · D⁻¹. That is why making the tool 2 mm shorter in Z pushes the points 2 mm deeper.
    • 
      
  • With no rotations this is simple subtraction; with angles the calculator does the full frame maths.
    • 
      
  • Photo reading runs on this device (Tesseract OCR), offline. Always check the values against the pendant before using them.
